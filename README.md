# tmass1/homebrew-tap

```bash
brew install --cask tmass1/tap/burn
brew install --cask tmass1/tap/bellhop
```

Burn — a menu-bar meter for AI plan limits (Claude, ChatGPT, Grok, Gemini, Cursor, Copilot) with pace, launchers
and a CLI. Source and releases: https://github.com/tmass1/burn

Bellhop — tucks the menu bar away, keeps the icons you choose, and runs any menu bar item from the keyboard.
Source and releases: https://github.com/tmass1/bellhop
